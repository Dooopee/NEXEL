## Знакомься, NEXEL

> **Не просто кнопка «Играть». Личное пространство для Minecraft.**

Один день — классическое выживание. Другой — техническая сборка с десятками модов. Третий — исследование нового загрузчика и эксперимент с шейдерами. NEXEL помогает не смешивать всё это в одну папку `.minecraft`.

Он объединяет установку и запуск игры, организацию отдельных сборок, управление контентом и оформление профиля. А визуальная система **Obsidian** делает знакомые действия понятными, собранными и выразительными: тёмная палитра, точная типографика, мягкое движение, минимальный визуальный шум.

## Всё для твоей игры

### Minecraft и сборки

| Возможность | Что это даёт |
| :--- | :--- |
| **Vanilla** | Оригинальная Minecraft Java Edition в выбранной версии. |
| **Fabric** | Сборки с Fabric-экосистемой модов и совместимым загрузчиком. |
| **Forge** | Установка Forge для поддерживаемых им версий игры. |
| **NeoForge** | Отдельный вариант модлоадера для совместимых версий Minecraft. |
| **Изолированные установки** | Свои игровые директории, компоненты и настройки для каждой сборки. |
| **Управление сборками** | Создание, выбор, настройка и клонирование. |
| **Импорт `.mrpack`** | Установка модпаков в поддерживаемом формате Modrinth. |
| **Java и память** | Подбор среды Java, настройка RAM и параметров запуска. |

**Важно:** конкретная пара «Minecraft + загрузчик» должна быть совместима. Поддержка нескольких загрузчиков не означает, что один и тот же мод подходит для всех них.

### Контент и персонализация

| Направление | Что доступно |
| :--- | :--- |
| **Modrinth** | Поиск модов и подходящих версий для выбранной сборки. |
| **Зависимости** | Подготовка зависимостей для поддерживаемых установочных сценариев. |
| **Управление модами** | Просмотр компонентов сборки, включение, отключение и удаление. |
| **Скины** | Локальная коллекция PNG-скинов, варианты Classic и Slim. |
| **3D-персонаж** | Предпросмотр выбранного образа в объёме. |
| **NEXEL ID** | Локальный профиль игрока, настройки оформления, игровое время и активность. |
| **Microsoft** | Отдельное подключение официального аккаунта, когда оно требуется для лицензированной игры и серверов. |

**Границы возможностей:** NEXEL ID в опубликованной версии не является облачным аккаунтом. Универсальная видимость локальных скинов другим игрокам на всех серверах не гарантируется. Синхронизация достижений Minecraft пока не подключена.

## Первый запуск без лишних шагов

**NEXEL распространяется как готовое приложение для Windows x64.** Для установки не нужны исходники, Node.js, pnpm или инструменты разработчика.

1. **Открой [последний релиз](https://github.com/Dooopee/NEXEL/releases/latest).** Прочитай его описание и совместимость.
2. **Скачай EXE-установщик** с обозначением `windows-x64-setup`. ZIP в этом выпуске содержит установщик, а **не portable-приложение**.
3. **Проверь файл**, если требуется: сравни SHA-256 с `SHA256SUMS.txt` из того же релиза.
4. **Установи NEXEL** обычным способом и открой приложение.
5. **Создай локальный профиль NEXEL ID** или подключи нужную учётную запись.
6. **Выбери Minecraft**, создай сборку с Vanilla / Fabric / Forge / NeoForge или импортируй `.mrpack`.
7. **Дождись установки компонентов**, добавь совместимые моды при необходимости и нажми **«Играть»**.

## Обновления и безопасность

Запускать установщик — это доверять ему свои файлы. Поэтому механизм обновления NEXEL проектируется вокруг **проверяемой целостности** и сохранения пользовательских данных.

```text
GitHub Releases
      |
      v
Подписанный nexel-update.json
      |
      v
Проверка подписи Ed25519
      |
      v
Скачивание установщика
      |
      v
Сверка размера и SHA-256
      |
      v
Установка с учётом совместимости
```

- **Ed25519** служит для проверки подписанного манифеста обновления.
- **SHA-256** позволяет сверить скачанный файл с ожидаемой контрольной суммой.
- **Отдельные игровые данные** помогают не смешивать файлы игры с установленной программой.
- **Резервные копии миров** остаются разумной мерой перед обновлением игры, сменой модлоадера или изменением набора модов.
- **Приватный исходный код** не размещён в публичном репозитории с установщиками.

> **Примечание о подписи Windows.** На текущем публичном выпуске отсутствует Windows Authenticode-подпись EXE. Ed25519-проверка манифеста не заменяет Authenticode, антивирусную проверку или резервное копирование. Если происхождение файла вызывает сомнения, не отключай защиту Windows и не запускай его.

## Частые вопросы

<details>
<summary><b>Можно ли играть без отдельного NEXEL ID или Microsoft?</b></summary>
<br />

NEXEL ID — локальный профиль лаунчера. Он не выдаёт лицензию Minecraft. Для игры и серверов, где требуется проверка владения Minecraft, используй соответствующий официальный Microsoft-аккаунт.

</details>

<details>
<summary><b>Где находятся мои миры и сборки?</b></summary>
<br />

Игровые данные хранятся отдельно от установленной программы. Не удаляй папку пользовательских данных при переустановке. Перед рисковыми изменениями всегда сохраняй отдельную копию важных миров.

</details>

<details>
<summary><b>Будут ли работать любые моды с любым загрузчиком?</b></summary>
<br />

Нет. Мод должен подходить и для версии Minecraft, и для Fabric / Forge / NeoForge. Доступность совместимого варианта зависит от автора мода и его дистрибуции.

</details>

<details>
<summary><b>Может ли NEXEL импортировать существующий модпак?</b></summary>
<br />

Поддерживается импорт `.mrpack`. Установка может требовать подключения к интернету и доступа к исходным файлам модпака.

</details>

<details>
<summary><b>Синхронизируется ли мой профиль между компьютерами?</b></summary>
<br />

Пока нет. NEXEL ID в текущем приложении локальный. Облачные функции находятся в разработке и не должны восприниматься как доступные.

</details>

<details>
<summary><b>Увидят ли все игроки мой локальный скин?</b></summary>
<br />

Не обязательно. Отображение скина у других игроков зависит от возможностей клиента и сервера. Внешний вид в 3D-превью самого лаунчера не означает универсальную поддержку в мультиплеере.

</details>

<details>
<summary><b>Почему Windows предупреждает об установщике?</b></summary>
<br />

## Технологии и принципы

NEXEL создан с использованием **Electron, React, TypeScript, Vite** и инструментов экосистемы Minecraft, включая **XMCL**. Стек и инструменты используются в приватном исходном проекте; публичный репозиторий содержит документацию, медиафайлы и готовые установщики.

Мы считаем важными следующие принципы:

- **Работоспособность раньше декоративности.** Любой элемент интерфейса должен помогать реальному сценарию игрока.
- **Уважение к данным.** Миры, аккаунты, сборки и настройки нельзя приносить в жертву внешнему виду.
- **Совместимость.** Изменения не должны необоснованно ломать старые установки и обновления.
- **Прозрачность статусов.** Реализованное отделяется от разрабатываемого, а концепции — от работающих функций.
- **Качество интерфейса.** Единая типографика, предсказуемая навигация, аккуратные состояния и внимание к деталям.

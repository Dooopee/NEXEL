# Развитие NEXEL

[← На главную](../README.md) · [Предложить функцию](https://github.com/Dooopee/NEXEL/issues/new?template=feature_request.yml)

NEXEL развивается как единое пространство для Minecraft: от выбора версии и модов до личного профиля и визуального стиля. Эта страница описывает направления развития и границы текущих возможностей. Конкретные изменения выходят вместе с [примечаниями к релизам](https://github.com/Dooopee/NEXEL/releases).

## Основа, которая уже есть

| Направление | Реализованные возможности |
| :--- | :--- |
| Запуск и сборки | Отдельные установки Minecraft, выбор версий, Vanilla / Fabric / Forge / NeoForge, импорт `.mrpack` |
| Игровой контент | Modrinth, установка зависимостей и управление компонентами сборки |
| Java | Подбор и установка среды для выбранной версии игры |
| Персонаж | Библиотека PNG, Classic / Slim, 3D-предпросмотр |
| Личное пространство | Локальный NEXEL ID, оформление профиля, учёт игрового времени и активности |
| Обновления | Центр обновлений с прогрессом загрузки, Ed25519-подписью манифеста и проверкой SHA-256 |
| Интерфейс | Оформление Obsidian, разделы главной, сборок, профиля, скинов и обновлений |

Наличие функции в приложении не означает, что каждый вариант модпака, сервера или внешнего провайдера проверен. Объём фактических проверок указан в отчёте конкретного выпуска.

## Направления в разработке

| Направление | Состояние |
| :--- | :--- |
| Друзья и NEXEL Messenger | В разработке; присутствие соответствующего экрана не означает готовность сервиса общения |
| Облачные интеграции и синхронизация | Подключение к работающему приложению не завершено; NEXEL ID остаётся локальным |
| Новости | Раздел обозначает направление развития |
| Studio | В разработке; функциональность уточняется по мере реализации |
| Достижения | Интерфейс показывает превью каталога; синхронизация достижений Minecraft не подключена |

Даты и порядок выпуска этих возможностей **не объявлены**. Ориентиром готовности служат реальные примечания к опубликованной версии.

## Текущие границы

- Проверенная платформа распространения — **Windows x64**. Выпуски для других платформ не заявлены.
- NEXEL ID не обеспечивает облачный вход или синхронизацию. Email необязателен; письма подтверждения не отправляются.
- Microsoft подключается отдельно для лицензированной игры и совместимых серверов.
- Видимость локального скина другим игрокам зависит от клиента и сервера.
- Встроенная поддержка содержит локальные справочные инструменты. Онлайн-оператор не подключён.
- Ed25519-подпись обновлений не заменяет Windows Authenticode-подпись EXE; последняя пока отсутствует.

## Как предложить полезное изменение

Опиши **сценарий игрока**: какое действие сейчас неудобно, чего хочется добиться и как должен выглядеть результат. Приложи пример, если он помогает понять идею. [Шаблон предложения](https://github.com/Dooopee/NEXEL/issues/new?template=feature_request.yml) уже содержит эти вопросы.

Публикация идеи не означает обещание реализации. Обсуждение помогает находить приоритеты и уточнять решение.

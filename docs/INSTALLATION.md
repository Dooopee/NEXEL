# Установка NEXEL

[← На главную](../README.md) · [Вопросы и ответы](FAQ.md) · [Поддержка](../SUPPORT.md)

NEXEL распространяется в виде готового установщика для **Windows x64**. Проверенная платформа текущих выпусков — Windows; отдельные выпуски для macOS и Linux не заявлены.

## Перед установкой

Нужны подключение к интернету для загрузки Minecraft, Java и компонентов, а также свободное место на диске. Объём загрузки и требования к памяти зависят от версии игры, загрузчика и модов. Единого значения для всех сборок нет.

Если уже играешь через NEXEL, сохрани резервную копию важных миров перед изменением версии Minecraft, загрузчика или набора модов.

## Первая установка

1. Открой [последний выпуск](https://github.com/Dooopee/NEXEL/releases/latest).
2. Прочитай описание выпуска и выбери EXE с обозначением `windows-x64-setup`.
3. Дождись завершения загрузки. При необходимости сверь файл с `SHA256SUMS.txt` из этого же релиза — [инструкция](SECURITY.md#ручная-проверка-sha-256).
4. Запусти установщик и выбери папку программы.
5. Открой NEXEL. При первом запуске создай локальный NEXEL ID или войди в существующий профиль.

**ZIP — альтернативная упаковка того же установщика.** Распакуй архив и запусти находящийся внутри EXE. Запуск программы прямо из ZIP не превращает её в portable-версию.

У EXE пока нет Windows Authenticode-подписи. Если Windows показывает предупреждение или блокирует файл, сначала проверь адрес загрузки, контрольную сумму и сведения о выпуске. Не отключай защиту системы для установки. При сомнениях остановись и обратись в [поддержку проекта](../SUPPORT.md).

## Первая сборка

1. Открой раздел **«Сборки»**.
2. Создай новую сборку и выбери версию Minecraft.
3. Выбери Vanilla либо подходящую версию Fabric, Forge или NeoForge.
4. Установи нужные компоненты. NEXEL подбирает и устанавливает Java для выбранной версии Minecraft.
5. Добавь совместимые моды, если они нужны.
6. Вернись к запуску выбранной сборки и нажми **«Играть»**.

Для разных версий игры и наборов модов удобнее использовать отдельные сборки. Это помогает сохранять их настройки и контент в собственном пространстве.

## Импорт модпака

NEXEL поддерживает импорт `.mrpack`. Выбери файл модпака через импорт сборки, дождись загрузки компонентов и проверь выбранную версию игры и загрузчика.

Моды должны соответствовать **версии Minecraft и загрузчику**. Поддержка Forge сама по себе не делает мод для Fabric совместимым с Forge. Если установка не завершилась, сохрани текст ошибки и сведения о модпаке для [отчёта](../SUPPORT.md).

## Профиль и Microsoft

NEXEL ID хранится на компьютере. Указание email не создаёт облачный аккаунт: письмо подтверждения и синхронизация профиля пока не подключены.

Microsoft подключается отдельно для лицензированной игры и серверов, которым он необходим. Наличие локального NEXEL ID не заменяет учётную запись Microsoft и право на Minecraft. [Подробнее об аккаунтах](FAQ.md#аккаунты-и-профиль).

## Обновление старой версии

Открой **центр обновлений** внутри NEXEL и запусти проверку. Совместимый клиент загрузит новую версию, проверит подпись манифеста и целостность установщика, затем перейдёт к установке. Заверши игровой сеанс перед обновлением программы.

Если обновление не предлагается:

1. Сравни установленную версию с [последним выпуском](https://github.com/Dooopee/NEXEL/releases/latest).
2. Прочитай примечания о совместимости именно этого выпуска.
3. Если там предусмотрена ручная установка, скачай официальный Setup.exe, закрой игру и NEXEL и установи новую версию поверх программы, сохранив папку игровых данных.

Для опубликованной 0.4.0 предусмотрен переход через существующий механизм обновлений. Промежуточным локальным сборкам и клиентам без совместимого updater может потребоваться разовая ручная установка. Сведения о конкретном переходе находятся в `INSTALLATION_COMPATIBILITY_RU.md`, если этот файл приложен к выпуску.

Миры, сборки и настройки хранятся отдельно от программы. Не удаляй папки данных при обновлении. Перед важными изменениями сохраняй отдельную копию ценных миров.

## Если что-то пошло не так

Посмотри [FAQ](FAQ.md) и собери данные по [инструкции поддержки](../SUPPORT.md). В отчёте укажи версию NEXEL, версию Windows, действие перед ошибкой и точный текст сообщения. Не прикладывай пароли, токены, базы аккаунтов и папки личных миров.
